# ED2 Sort Analysis

## Trabalho de ED2:

Uma empresa necessita processar conjuntos de dados numéricos provenientes de 
diferentes fontes. Dependendo da origem, esses dados podem estar 
completamente desordenados, parcialmente ordenados, ordenados ou 
organizados em ordem inversa.

## Funcionalidades:

1. Gerar um conjunto de dados;
2. Exibir os dados gerados;
3. Ordenar utilizando Selection Sort;
4. Ordenar utilizando Insertion Sort;
5. Ordenar utilizando Shell Sort;
6. Ordenar utilizando Quick Sort;
7. Ordenar utilizando Heap Sort;
8. Executar e comparar todos os algoritmos;
9. Encerrar o programa.

### Obs:

O sistema deverá permitir que o usuário determine o tamanho N do vetor a ser 
utilizado nos experimentos.
